# Library Management System (OOP in C++)

A persistent, menu-driven C++17 library application. Book and user records are automatically stored in `books.txt` and `users.txt` in the program's working directory.

## OOP concepts used

- Classes and objects: `Book`, `User`, and `Library`
- Constructors and encapsulation through private data and public methods
- File handling with `fstream`
- Composition: the library owns collections of books and users

## Features

- Add, remove, update, search, and list books
- Register users, issue/return books, and view all issued books
- Unique IDs, duplicate checks, availability tracking, validation, and persistent records
